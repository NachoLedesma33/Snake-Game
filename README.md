# Snake Game

Un juego clásico de Snake desarrollado con HTML5, CSS3 y JavaScript puro, featuring un diseño moderno y una experiencia de usuario optimizada.

## Descripción

Snake Game es una implementación moderna del clásico juego de la serpiente. Controla a la serpiente para comer comida, crecer y evitar colisiones. El juego incluye una interfaz de usuario elegante con gradientes, animaciones y un diseño responsivo.

## Características

### Gameplay

- **Tablero de 10x10**: Espacio de juego optimizado
- **Controles intuitivos**: Usa las teclas de flecha para mover la serpiente
- **Sistema de puntuación**: Gana puntos por cada comida consumida
- **Detección de colisiones**: Game Over al chocar contra paredes o sí mismo

### Interfaz de Usuario

- **Diseño moderno**: Gradientes púrpura-azul con efectos glassmorphism
- **Animaciones suaves**: Pulsos en la serpiente y comida
- **Layout responsivo**: Adaptable a desktop, tablet y móvil
- **Card de instrucciones**: Guía completa de jugabilidad al costado

### Características Técnicas

- **HTML5 semántico**: Estructura web moderna y accesible
- **CSS3 puro**: Sin frameworks, solo CSS vanilla
- **JavaScript ES6+**: Código moderno y eficiente
- **Diseño responsivo**: Media queries para todos los dispositivos

## Cómo Jugar

### Controles

- **Arrow Up ( flecha arriba)**: Mover hacia arriba
- **Arrow Down (flecha abajo)**: Mover hacia abajo
- **Arrow Left (flecha izquierda)**: Mover hacia la izquierda
- **Arrow Right (flecha derecha)**: Mover hacia la derecha

### Objetivo

Controla la serpiente para comer la comida roja y crecer lo más posible. ¡No choques contra las paredes o contra tu propio cuerpo!

### Consejos

- Planifica tus movimientos con anticipación
- No te acerques demasiado a los bordes
- La comida aparece en lugares aleatorios
- Cada comida hace que la serpiente crezca
